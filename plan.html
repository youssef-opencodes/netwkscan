📡 NMD PROJECT - TEAM ORGANIZATION

Network Monitoring Dashboard | Version 1.0 | January 2026

📋 Executive Summary

The NMD Project is a Python-based desktop application for network monitoring and device tracking.

🎯 Key Features

  • Real-time device discovery via Nmap
  • Automatic scheduled scanning
  • Manual custom scans with Nmap options
  • Connection history and logging
  • Modern dark-themed GUI
